Healthcare Data Analysis Using SQL & Power BI

This project focuses on analyzing a healthcare dataset using SQL for data cleaning, transformation, and exploration, along with Power BI for interactive data visualization. The dataset includes patient demographics, medical conditions, hospital details, admission information, and billing amounts. The goal of the project is to identify meaningful insights that can support healthcare organizations in making data-driven decisions.

SQL was used to clean the dataset by handling missing values, removing duplicate records, standardizing gender and blood type values, and converting billing amounts into a proper numeric format. Analytical queries were performed to explore patient trends, calculate average billing amounts, identify common medical conditions, and compare hospital-wise performance.

Power BI was used to build a visually appealing dashboard displaying key metrics such as total patients, total billing amount, maximum and minimum charges, and average billing. Charts were created to show patient distribution based on blood type, admission type, test results, and yearly trends from 2018 to 2023. Slicers for medical conditions and top hospitals were added for interactive analysis.

Overall, this project demonstrates how SQL and Power BI can work together to transform raw healthcare data into valuable insights that improve decision-making and healthcare management.
